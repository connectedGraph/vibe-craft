# Bri.Fix - Native Expression Refiner

A lightweight, client-side web SPA designed to help you polish, refine, and accumulate native English expressions. It features a side-by-side comparison interface to compare your original drafts with refined native expressions.

## Key Features

*   **Side-by-Side Comparison**: Clear split view to compare original drafts against polished, native expressions.
*   **Expression Highlighter**: Highlight specific words and phrases to analyze differences in sentence structure and word choices.
*   **Library Management**: Organize and save your polished expressions locally.
*   **Zero Dependencies**: Single HTML file powered by Tailwind CSS and vanilla Javascript.

## Getting Started

1. Open index.html directly in any modern web browser.

# 中文版

一款轻量级、本地运行的英语地道表达积累与润色工具。它通过左右分屏对比，帮助你直观对比原始表达与润色后的地道英语表达。

## 核心特性

*   **左右对比视图**：清晰的双栏分屏，直观对比你撰写的初稿与润色后的地道表达。
*   **表达高亮标记**：高亮词汇与短语，方便深入剖析句型结构与遣词造句的差异。
*   **本地文库管理**：在本地存储、归类并管理你的地道表达库。
*   **零构建依赖**：纯 HTML 网页，由 Tailwind CSS 与原生 Javascript 驱动。

## 快速开始

1. 直接在任意现代浏览器中打开 index.html 即可开始使用。

中文排版易读性分析

对阅读障碍（Dyslexia）群体而言，文字排版的好坏决定了阅读是“获取信息”还是“受罪”。视觉拥挤（Visual Crowding）是核心难点，当字符间距过小时，大脑会难以区分笔画归属，产生文字连在一起或者在“跳舞”的错觉。

请尝试左侧的“字间距 (Letter Spacing)”滑块。对于有视觉压力的读者，增加 1-2px 的字间距往往能让阅读速度提升 20% 以上。同时，思源黑体这类无衬线字体，由于笔画末端没有多余的修饰，在小字号下通常比宋体更清晰。

高对比度也并非总是好事。纯黑 (#000) 与纯白 (#FFF) 的剧烈对比会产生闪烁感。尝试将背景调成米黄色 (#F4ECD8)，你会发现眼睛的紧绷感瞬间缓解。

Dyslexia-Friendly English

English letters are notorious for their symmetry. Letters like 'b' and 'd', 'p' and 'q' are just mirrored versions of each other. In many fonts, these are perfect geometrical flips, which makes rotation errors very common.

b d p q | u n | I l 1

Switch the font to "OpenDyslexic". Notice how the bottom of each letter is weighted? This provides a "gravity" effect, helping your brain understand which side is down and preventing mental rotation. Another great choice is "Lexend", which was mathematically designed to reduce visual stress.

Increasing Word Spacing can also prevent words from blending into a gray blur, allowing the brain to process one unit of meaning at a time.

编程字符区分度

代码阅读不仅是逻辑理解，更是字符匹配。如果排版不当，简单的符号混淆可能导致灾难性的 Debug。

function processInput(id, value) {
  // Can you distinguish '1', 'l', and 'I'?
  const filter_ID = "l1I"; 
  const result = id === 1 || id === 'l' ? value : null;
  
  // Is 'rn' looking like 'm'?
  const kernel = "kernal_process_rn";
  
  return result;
}
